# 意味を守る設計

何を情報として拾う価値があると考えるか。意味、美、畏敬、信仰、同一性、意図、主観、儀礼、物語、文化を、隠れた前提のままにせず設計へ接続します。

Spiritual Engineeringは設計哲学、情報子工学は研究・工学領域、Context Engineeringは実装技法の一つです。測れない部分を無価値として捨てず、共有可能な観測と一人称の経験を分けて記録します。

画像なら生成枚数や画素品質に加え、作者が作品として採用できるか。音楽なら分離度や音圧に加え、繰り返し聴きたいものか。目的を壊したまま代理指標だけを改善していないか比較できます。

宗教・神学・科学・工学・芸術のどれかを他の棚の最終裁判官にしません。異なる意味は原典を保って別Presentationとして接続します。
