# Worldとゲーミング宇宙論

ゲーミング宇宙論は、宇宙・社会・制度・人生を、プレイヤー・役割・規則・観測点を持つMMO的構造として読む思想です。現実の死活、身体、資源、地域格差を軽くする遊びではなく、それらを設計と運営の問いへ戻す視点として原典に置かれています。

系譜は古神道・琉球神道等の信仰のfork、テクノアニミズム、ゲーミング宇宙論へ接続します。これは作者の信仰・思想の紹介であり、別宗派の教義や物理学を同一化する説明ではありません。

読む、疑う、遊ぶ、解釈する、forkする、退出する入口を残します。自分のWorldで採用する規則と他者のWorldへの権限を分け、物語上の役職から他者への操作権を生成しません。
