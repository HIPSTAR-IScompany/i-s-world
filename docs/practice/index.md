# 紙とペンから始める

入門は信じることの強制より、一回のセッションから始められます。紙とペンで、World、参加者の役割、目的、扱いたい出来事を置いてみる。

1. 自分の体験・問い・願いを自分の言葉で記録する。
2. 相手の解釈を正解・誤答に固定せず、Worldと文脈を確認する。
3. 同じ出来事への別解釈を、元の記録を消さずに並べる。
4. 合わないときの停止・退出・forkを残す。
5. 共有したい部分だけを作者・出典とともに持ち運ぶ。

これは原典のTRPGセッションとリプレイの入口を再編集した案内です。新しい儀礼・教義・医療的効能や、同一の霊的体験の再現を制定する手順ではありません。

技術で試したい部分は、目的と観測条件を明示して研究・実装の棚へ渡せます。信仰や物語をその棚へ移すことは参加条件ではありません。
